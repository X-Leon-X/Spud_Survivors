# Spud Survivors

**Play now: https://x-leon-x.github.io/Spud_Survivors/**

A browser-based arena survival game about a potato with too many weapons and no
plan. Fight against waves of blobs and other enemies come for you and between
each wave you spend scrap on upgrades that will hopefully outpace them. Inspired by
Brotato.

No install, download, or plugins. It runs entirely in the browser.

## How it works

You survive timed waves in a single arena. Your weapons aim and fire on their
own, so during the wave, all you control is where you move.

- **Survive the wave.** Enemies pour in from the edges and get tougher every
  round. 
- **Collect scrap.** Dropped by everything you kill, plus crates and trees you
  can break open in the arena.
- **Shop between waves.** Buy weapons and items in the Field Market. Buy two of
  the same thing and you can merge them into a stronger version.
- **Pick a mutation.** Every wave ends with a choice of body upgrades.
- **Repeat until you die.** Then read the run summary and go again.

Enemies scale hard as the run goes on, so a build that carried you through wave
5 will not work in wave 15.

## Controls

| Input | Action |
|---|---|
| `WASD` / arrow keys | Move (aiming and firing are automatic) |
| `ESC` | Pause menu: resume, abandon run, volume, mute, screen shake |
| `M` | Mute toggle, any time |
| `R` | Restart once a run has ended |
| Mouse | Click shop cards between waves to buy, merge and recycle |

## Characters

Three potatoes, each with different traits:

- **Sprout** is the balanced starter with no downside.
- **Chunk** is a slow armoured heavy hitter with a big health pool.
- **Zip** is a fast, lucky scavenger who finds more loot but hits softer and dies quicker.
